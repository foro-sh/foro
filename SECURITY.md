# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's
[Security Advisories](https://github.com/foro-sh/foro/security/advisories/new)
rather than opening a public issue.

We'll acknowledge your report within a few days and keep you updated as we
work on a fix.

## Supported Versions

Only the latest published release of each package (`foro` on PyPI,
`@foro-sh/foro` on npm) is supported. Please upgrade before reporting an
issue that may already be fixed.
